Chaque tentative peut gagner son bonus

Les vérifications construisent deux essais réussis pour chacun des douze modules, avec des cartes physiques différentes. Elles vérifient aussi que des tiers, valeurs de dés ou effets répartis entre les deux essais ne peuvent jamais être combinés pour fabriquer un bonus.

Ce qui a été vérifié

  • Une chute annule tout le score et le bonus de cet essai.
  • Le premier trick respecte le module ; les modules à deux types imposent toujours les deux types avant d’encaisser.
  • Le dé gelé doit traverser un jet entre deux tricks et être utilisé. Continuer conserve le gel.
  • Le Coping Bleu reconnaît une relance ou un ±1 utile après un premier jet impossible ; modifier volontairement un jet initialement possible ne crée pas un sauvetage.
  • Les étoiles comptent comme des 1 physiques pour les paires et les valeurs différentes, même si leur joker résout une autre valeur.
  • Les bonus de cartes, celui du troisième trick et celui du module sont distincts.
  • Les 85 cartes physiques sont conservées, les commandes respectent le moteur et les stocks de jetons restent non négatifs.
  • Le score affiché par le moteur correspond au score enregistré dans l’historique.

Limites et reproduction

600 parties utilisent quatre styles de contrôleurs ; 600 autres utilisent des contrôleurs sans préférence de coût. Les paramètres de prudence propres aux places restent ceux du jeu dans les deux groupes. Les dés, les jetons et les cartes passent par le même moteur que les règles réelles. Les contrôleurs n’accèdent ni aux jets futurs ni à la pioche cachée. Leurs estimations de planification n’attribuent jamais de points.

Ces résultats valident le plancher d’activation dans ce modèle lorsque les indicateurs ci-dessus sont positifs. Ils ne démontrent pas un équilibre humain définitif ou une stratégie optimale. Les obligations et les PV restent inchangés.
